ニャウンサー Ver.5.0　オンライン版セットアップ
=================================================

■ 1. Supabaseプロジェクトを作る

Supabaseで新規プロジェクトを1つ作成してください。
このアプリはRealtime Broadcast / Presenceだけを使用するため、
テーブル作成やSQL実行は不要です。

Supabase Dashboardから次の2つを確認します。

・Project URL
・Publishable Key
  （旧形式のプロジェクトでは anon key でも利用できます）

注意：
service_role key / secret key は絶対にブラウザ用ファイルへ入れないでください。


■ 2. online-config.js を編集

ZIP内の

  online-config.js

をメモ帳などで開きます。

例：

window.NYOUNCER_ONLINE_CONFIG = {
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  supabaseKey: "sb_publishable_xxxxxxxxxxxxx",

  publicBaseUrl: "https://あなたの公開先/nyouncer-draft/"
};

保存してください。


■ 3. 公開版をアップロード

index.html
online-config.js
assets フォルダ

など、ZIP内のファイルをフォルダ構成そのままで
GitHub Pages等の静的ホスティングへ公開してください。

publicBaseUrl は公開したトップページのURLにします。

例：
https://example.github.io/nyouncer-draft/


■ 4. 主催者はローカル版を起動

AivisSpeechを起動したあと、

  起動.bat

を実行します。

主催者：
  http://127.0.0.1:8765/

で使います。

主催者はローカル版なのでAivisSpeech Engine
  http://127.0.0.1:10101
へ接続できます。


■ 5. オンライン会場を作成

ホーム画面で

  🌐 新しいオンライン会場

を押します。

ランダムな7文字のルームコードと、
指名席4つの秘密トークンが自動生成されます。

主催者画面には以下が表示されます。

・観戦席URL ×1
・指名席URL ×4


■ 6. URLを配布

観戦者には「観戦席URL」を送ります。

4人の指名実施者には、
それぞれ本人の指名席URLだけを送ります。

指名席URLには秘密トークンが含まれています。
他の人へ転送しないようにしてください。


■ 7. 参加時

観戦者：
URLを開く
→ 表示名を入力
→ 観戦席
→ 会場チャット参加

指名実施者：
専用URLを開く
→ 表示名を入力
→ 自分の指名席
→ 指名 / 封筒選択 / 開封 / 会場チャット

主催者：
主催者画面で進行
→ 会場チャットも利用可能


■ 8. リアルタイム同期

主催者が正本を保持します。

指名実施者
→ 指名コマンドを専用チャンネルで主催者へ送信
→ 主催者が内容を検証して確定
→ 各画面へ同期

観戦者には発表前の指名内容は送信されません。

指名発表では、
1人目 → 2人目 → 3人目 → 4人目
の順次発表状態がリアルタイムに反映されます。

競合後は封筒抽選へ移行し、
敗者だけが再指名できます。


■ 9. 主催者PCを閉じた場合

主催者ブラウザが親機なので、
閉じている間は指名操作・チャット確定・同期が止まります。

同じPC・同じブラウザで再度アプリを開くと、
ホームに

  ↻ 前回の会場 XXXXXXX を再開

が表示されます。

そこから同じルームへ戻れます。


■ 10. テスト方法

本番前に最低2台で確認することをおすすめします。

PC：
主催者

スマホ：
観戦URL

まずチャットが双方に表示されることを確認してください。

その後、
別ブラウザ/別スマホで指名席URLを開き、
グループ指名が主催者へ反映されることを確認してください。
